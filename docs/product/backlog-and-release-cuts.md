# Backlog and Release Cuts

## V1 Must

1. Firebase Authentication and tenant context propagation.
2. Note/self-talk create API and UI.
3. Mixed history list (notes + conversation summaries) with default recent 10.
4. Embedding generation pipeline.
5. Ask-AI recall endpoint.
6. Ask mode END summary storage (summary_text + references only).
7. Basic observability and AI cost tracking.

## V1 Should

1. Tag suggestions.
2. Optional mood score input.
3. Citation chips in UI.
4. Retry and fallback behavior for AI failures.

## V1 Could

1. Voice capture.
2. Reminder nudges.
3. Topic trend visualization.

## V1.1 Candidates

1. Summary generation endpoint.
2. Personalized summary style.
3. Better query rewriting for recall.
4. Export memories and summaries.
5. Multimedia capture/retrieval (images, audio, video).

## Cut Rules

1. Keep security, privacy, and grounding requirements in all release cuts.
2. Defer cosmetic enhancements that do not improve capture or recall quality.
3. Defer advanced AI features until retrieval relevance is stable.
